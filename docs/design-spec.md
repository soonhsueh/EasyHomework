# 设计规范 — 小学数学练习题生成器

## 1. 设计理念

- **简洁直观**：减少操作步骤，核心功能一触即达
- **活泼友好**：温暖配色、圆角卡片、大图标，适合小学生和家长
- **专注内容**：UI 为题目内容服务，不做多余装饰

## 2. 配色方案

| 色名 | 色值 | 用途 |
|------|------|------|
| 主色-蓝 | `#4A90D9` | 按钮、选中态、导航 |
| 辅色-橙 | `#FF9500` | 强调元素、生成按钮 |
| 点缀-绿 | `#34C759` | 成功提示、完成标记 |
| 背景-奶油白 | `#FFF8F0` | 页面背景 |
| 卡片白 | `#FFFFFF` | 卡片、面板背景 |
| 文字-深灰 | `#333333` | 正文文字 |
| 文字-中灰 | `#666666` | 辅助文字 |
| 文字-浅灰 | `#999999` | 占位、禁用态 |

## 3. 字体规范

| 层级 | 大小 (rpx) | 字重 | 用途 |
|------|-----------|------|------|
| H1 | 48 | 700 | 页面标题 |
| H2 | 40 | 600 | 区段标题 |
| H3 | 32 | 500 | 卡片标题 |
| Body | 28 | 400 | 正文 |
| Caption | 24 | 400 | 辅助说明 |
| Small | 20 | 400 | 标签、角标 |

## 4. 组件规范

### 4.1 圆角
- 页面卡片：`20rpx`
- 按钮：`16rpx`
- 标签/徽章：`8rpx`

### 4.2 阴影
- 卡片：`0 4rpx 20rpx rgba(0,0,0,0.08)`
- 悬浮按钮：`0 8rpx 30rpx rgba(0,0,0,0.15)`

### 4.3 间距
- 页面内边距：`40rpx`
- 卡片间距：`24rpx`
- 元素内边距：`24rpx`

## 6. A4 题目页排版参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 标题文字 | "小学数学练习题" | 页面顶部居中 |
| 信息行 | "姓名：______  日期：____年__月__日" | 标题下方 |
| 题目区起始 Y | 200 px | 信息行下方 |
| 题号格式 | "1." 后跟算式 | |
| 横式列数 | 2-3 列 | 自适应 |
| 竖式列数 | 1-2 列 | 竖式占位大 |
| 应用题列数 | 1 列 | 通栏排版 |
| 行间距 | 80 px | 横式题 |
| 竖式行间距 | 140 px | 竖式题 |
| 页脚 | "第 1 页" | 页面底部居中 |

## 7. 交互规范

- 卡片点击：轻微缩放反馈（scale 0.96）
- 页面切换：`navigateTo` 右滑进入，左上角返回
- 生成中：显示 loading 状态（1-2 秒）
- 保存成功：绿色 Toast "已保存到相册"
- 保存失败：提示去设置开启相册权限
- 所有按钮：最小点击区域 44×44 pt（微信规范）
