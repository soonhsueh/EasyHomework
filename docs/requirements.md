# 产品需求文档 — 小学数学练习题生成器

## 1. 产品概述

一款微信小程序，面向小学生家长，自动生成 A4 尺寸的数学练习题图片，可保存到手机相册后打印。

## 2. 目标用户

- **主要用户**：小学1-6年级学生的家长
- **间接用户**：小学生（查看/使用练习题）

## 3. 功能需求

### 3.1 年级选择
- 提供 1-6 年级选项，以卡片形式展示
- 每个年级对应不同的题目难度（基于北京版教材）

### 3.2 题型选择
- 根据所选年级，动态展示可用的题型
- 题型包括：加法、减法、乘法、除法、混合运算、竖式计算、应用题

### 3.3 题目生成
- 随机生成一页 A4 练习题（约 10-20 题，取决于题型）
- 同时生成对应的答案页
- 所有题目答案正确、符合年级难度约束

### 3.4 预览
- 在页面中预览生成的题目图片
- 支持题目页和答案页切换查看

### 3.5 保存
- 将题目图片保存到手机相册
- 将答案图片保存到手机相册
- 保存成功有 Toast 提示

### 3.6 重新生成
- 点击"换一题"可重新随机生成
- 每次生成的题目不重复

## 4. 非功能需求

### 4.1 教材标准
- 难度对标北京版小学数学教材
- 覆盖 1-6 年级上/下学期知识点

### 4.2 打印质量
- 图片为 A4 比例，约 150dpi 分辨率
- 打印后文字清晰可读

### 4.3 性能
- 题目生成 + 渲染在 2 秒内完成
- 小程序包体积 < 2MB

### 4.4 扩展性
- 预留语文、英语科目接入能力
- 科目间共享页面框架和渲染引擎

## 5. 验收标准

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AC-1 | 年级选择 | 6 个年级卡片正常显示和点击 |
| AC-2 | 题型联动 | 低年级不显示未学题型（如一年级无除法） |
| AC-3 | 题目正确 | 随机生成 100 题，无答案错误 |
| AC-4 | 竖式格式 | 竖式计算数位对齐，格式规范 |
| AC-5 | 应用题 | 文字通顺，场景合理 |
| AC-6 | 图片导出 | A4 比例，保存后相册可见 |
| AC-7 | 题目/答案对应 | 题目页和答案页一一对应 |

## 6. 项目约束

- 纯前端实现，无后端服务器
- 微信小程序原生框架，不引入第三方 UI 库
- 所有资源本地化，不依赖外部 API
- 仅支持简体中文

## 7. 版本规划

- v1.0：数学 1-6 年级，全题型，基础功能
- v1.1：应用题配图
- v2.0：语文科目
- v3.0：英语科目
