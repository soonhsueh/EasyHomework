# EasyHomework

EasyHomework 是一个微信小程序项目，用于生成小学数学练习题。项目面向家长和小学生，支持按年级和题型生成适合打印的 A4 练习题图片，并提供答案页预览与保存能力。

## 项目功能

- 支持小学 1-6 年级数学练习题生成
- 支持加法、减法、乘法、除法、混合运算、竖式计算和应用题等题型
- 可生成题目页和答案页
- 可在小程序内预览练习题
- 支持保存生成图片，方便打印使用

## 目录说明

- `miniprogram/`：微信小程序源码
- `data/`：教材和知识点映射数据
- `docs/`：需求、设计和技术文档
- `devlog/`：开发记录

## 开发说明

使用微信开发者工具导入本项目即可预览和调试。项目为纯前端小程序实现，不依赖后端服务。
